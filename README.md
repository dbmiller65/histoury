# Histoury

Discover interesting historical facts about wherever you are — or anywhere you're curious about — read aloud on demand.

## Support

Having an issue or a question about Histoury? Open an issue on this repository:

https://github.com/dbmiller65/histoury/issues

## Privacy

Histoury uses your location only to generate the historical fact you asked for. It's sent to the app's own backend to produce that response, and it is not shared with any third party or retained beyond handling your request.
